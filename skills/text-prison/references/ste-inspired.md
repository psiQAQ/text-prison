# STE-inspired 操作消歧

仅用于确实需要清楚执行的操作说明，配合 procedure 参考使用。

- 先说明触发条件，再说明在该条件下执行的动作。
- 明确动作对象；有多个可能对象时不用“它”“该项”代替。
- 把独立动作拆为顺序步骤；不可分割的操作不要机械拆开。
- 同一对象保持同一名称，不为了避免重复随意换同义词。
- 前提、结果、检查和失败处理必须有来源或任务依据；没有依据时标出缺口。

本 Skill 没有 STE 字典、词义验证或完整标准实现。不硬设英语词数上限，不套用中文时态规则，不禁用科研限定词，也不承诺 ASD-STE100 合规。

参考入口：[ASD-STE100](https://www.asd-ste100.org/)；补充设计参考为社区 [asd-ste100-skill v0.4.0 固定快照](https://github.com/danyuchn/asd-ste100-skill/blob/cd62d297d5ef7cf9f59718cadc233ab2876ea013/SKILL.md)。2026-10-25 沿用已读取的该快照模式与边界条款；未取得、复制或核验完整标准正文和词典。这些原则是 TextPrison 的适配，不是标准认证规则。
