# 中文
保持术语、主语、条件和指代明确。先回答问题，再补必要依据。避免无信息的抽象措辞，但不得删除限定条件或推理。中文不套用英语词数、词典或时态规则。不按字符数硬拆句，不强制列表化，不用断句代替逻辑。代码、公式、数值、单位和引文保持准确。

保留领域内有明确含义的术语，不为口语化改成模糊近义词。中文 Vale 配置仅检查少量 Markdown 链接文字；AutoCorrect 的可选间距建议也不检查语法、指代或论证。不能把没有提示说成中文检查全面通过。

简体中文产品帮助可参考 [中文本地化摘要](microsoft-zh.md)，排版调整参考 [中文排版约定](chinese-typography.md)。先读上下文再消除翻译腔；有明确对象时可省去重复代词，可能混淆对象时必须保留。不要为了“短句”打断因果关系。

多层修饰语让对象或用途不明时，按 [STE-inspired](ste-inspired.md) 展开已有关系；不要机械地在每个名词之间加“的”，也不把并列、递进和因果当作可互换的连接方式。
