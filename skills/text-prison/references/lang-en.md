# English
Use consistent technical terms and direct syntax. Prefer active voice when it clarifies the actor. Keep necessary articles, conjunctions, and qualifiers. Sentence-length limits are advisory outside an explicitly verified standard. Do not claim dictionary or word-sense validation. Preserve domain vocabulary, code, and mathematics.

Choose one brand style only when the task needs it. Treat diagnostic suggestions as contextual advice, especially for quotations, UI labels, gestures and scientific qualifications.

An explicit relative marker such as `that` can clarify an object relative clause; omission is not always an error. Use [STE-inspired guidance](ste-inspired.md) for ambiguous noun chains and interrupted clauses, while preserving fixed terms, necessary passive constructions, and modal qualifications.

Use the same guidance when stock introductions, closing remarks, forced contrasts or vague wording obstruct the point. Remove phrases with no useful function, but preserve real contrasts, necessary context, supported emphasis and qualifications. Do not retain a difficult expression merely to preserve its original style, or rewrite clear prose merely because it resembles AI output. Optional phrase diagnostics are available only when explicitly selected; see the [Vale configuration guide](../vale/README.md).
