# 中文排版约定

只在用户要求排版调整或项目已有约定需要维护时使用。优先采用项目明确配置，其次沿用现有文稿的一致写法，再考虑下面的社区建议；没有配置不等于允许重排全文。

- 中文与西文、数字之间可加空格以便辨认。这是可选风格，不能把没有空格判成语义错误。
- 专有名词、产品名、界面标签和标识符保持实际拼写。官方名称的内部空格不能由通用排版规则决定。
- 数字与单位、百分号、角度、上下标和公式遵循领域或投稿规范，社区示例不能替代科学格式要求。不改数值、正负号或单位归属。
- 中文叙述可按项目惯例使用中文标点；英文整句、原样引用、命令和数学表达保留自身标点。界面与文档的约定可能不同。
- 链接旁空格、直角引号等存在风格分歧，不作为统一要求。局部调整不改链接地址、标题锚点或其他段落。

需要机械建议时按 [AutoCorrect 说明](autocorrect.md)调用。工具只提供候选，不能据其输出整行替换而改变受保护内容。未采纳的偏好建议可保留，不以“零提示”为完成标准。
