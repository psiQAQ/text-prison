当前 agy 的 `init.tools` 来自全局工具目录，不能据此判断所选 agent 的执行权限。[静态证据](agy-init-catalog.json)只针对所记二进制 SHA-256，不能代替运行验证。执行约束由每个任务目录内的全工具拒绝 hook 实现；普通评审出现任何工具尝试都会失败。首次两次初始化因错误地要求目录广告为空而停止，提示未发送；两次均保留并计入预算。负向探针故意触发工具拒绝，所以普通运行状态为 `failed`，独立探针验收为 `Passed`，不会被算作模型评审或七个就绪 smoke 之一。

原始事件、提示、评审数据库和本机路径留在被 Git 忽略的 `runs/`。本目录保存可核对的工程摘要与哈希，旧 `validation/v0.2/` 不改写。初期界面截图中的 24/72 是拍摄时进度；最终界面另见 `QA-final.md`。一次重试导入使用旧缓存造成的界面计数差异已用原始侧车修复，未新增推理，见 [投影修复记录](projection-repair.json)。

费用总额仍有未知项：agy 未提供可核验的金额，缓存输入语义和内部模型请求数也不完整；Pi 的美元值只是目录估算。报告分别列出已观测部分与覆盖率，不把缺失填成零。

27 条继承的旧 Pi 记录当时没有 `loaded_adapter_hash` 和 `observed_usage`：其运行时加载源码身份仍为未知，后者可由原始事件重放派生。原始权威用量字段全部一致；这项兼容说明没有补写旧记录，也没有将未记录的信息当作已验证事实。

恢复评审时丢失 `invalid_review` 状态的缺陷已修复，并经失败复现和完整回归验证。4 条衍生投影用保留的校验原因重建；旧投影另存，原始模型事件不变，未新增推理。最终显示为 13 份格式无效和 2 份配额失败，见 [恢复状态修复](invalid-review-resume.json)。
