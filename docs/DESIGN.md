# TextPrison 当前设计范围

日期：2026-10-25。当前处于清理后的指令阶段；Vale 与新的优化选项交互尚未实施。来源保留在 [RELATED_WORK.md](RELATED_WORK.md) 和 [sources.json](../sources.json)。

## 当前职责

TextPrison 按输出用途选择规则，帮助写作者保护原意、澄清对象与条件、组织信息。它不是完整 ASD-STE100 认证器。当前没有机械检查器、独立语义评委或实际效果评测工具。

| 用途 | 当前指导重点 |
|---|---|
| explanation | 先回答问题，再解释机制、依据和边界 |
| procedure | 前提和条件先于动作，不补造失败处理策略 |
| reference | 保留类型、默认值、范围、单位、版本与标识符 |
| research | 保留模态、否定、误差、适用条件和引用 |
| agent-spec | 明确目标、权限、作用域与停止条件，不增加授权 |
| structured | 维持用户指定的机器格式，不应用自然语言文风规则 |

主 Skill 只读取适用用途和语言的参考文件。混合文档由写作者按章节用途处理，不宣称具有自动分段分类器。中文不套用英文词数或词典要求。

## 不变的内容保护

表达优化不得改变主体、对象、否定、条件、可能与必然、数字及单位归属、因果、版本和引用对应。代码、命令、公式和原样引文默认保护。资料不足时指出缺口，不编造事实、前提或验收要求。

来源核对由当前写作者在任务内进行，不额外调用评审模型。当前无工具输出可证明文本语义保真；不得把指令遵循写成检查通过。

## 已退役范围与后续门禁

项目不再维护或运行测试套件、Agent 实战、模型评委、触发实验、A/B 实验及评审网页。旧代码和已提交报告可在 Git 历史中查阅；原始 ZIP 与固定子模块保留为参考，不作为当前执行入口。

新方案将单独落盘、提交并交由用户指定的 Opus 审阅。完成修订后等待用户确认，再实施统一 Skill、Vale 配置和安装使用介绍。此处不提前声明新功能已可用。
