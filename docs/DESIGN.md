# TextPrison 当前设计范围

日期：2026-10-25。当前范围为统一 Skill、Vale、可选中文排版支持，以及 npx 项目/全局安装说明和 Python 项目安装器。文件、安装和运行证据分别记录。来源保留在 [RELATED_WORK.md](RELATED_WORK.md) 和 [sources.json](../sources.json)。

## 当前职责

TextPrison 按输出用途选择规则，帮助写作者保护原意、澄清对象与条件、组织信息。Skill 负责语义和任务判断；Vale 提供显式风格、术语和链接诊断；AutoCorrect 可选地提供中文排版建议；参考库提供适用条件、例外和来源。它不是完整 ASD-STE100 认证器，没有独立语义评委或效果评测工具。

| 用途 | 当前指导重点 |
|---|---|
| explanation | 先回答问题，再解释机制、依据和边界 |
| procedure | 前提和条件先于动作，不补造失败处理策略 |
| reference | 保留类型、默认值、范围、单位、版本与标识符 |
| research | 保留模态、否定、误差、适用条件和引用 |
| agent-spec | 明确目标、权限、作用域与停止条件，不增加授权 |

主 Skill 只读取适用用途、语言和写作风格的参考文件。纯机器格式输出不进入文风优化。混合文档由写作者按章节用途处理，不宣称具有自动分段分类器。中文不套用英文词数或词典要求。产品帮助在相应用途上采用 Microsoft 指导，不增加第二个 Skill。

[STE-inspired](../skills/text-prison/references/ste-inspired.md) 为所有用途提供按需消歧：出现术语、指代、条件与动作或结构歧义时才加载。它借鉴官方介绍和固定社区快照，将通用方法与本项目内容保护结合；不增加一种用途，也不改变机械规则。科研限定、API 定义和 Agent 权限不因简化表达而改变；完整规则及编辑示例以该参考为准。

## 任务流程

先读取文档与项目约定，确定读者、用途、语言和可编辑范围。有实质取舍时给出 2–3 个具体选项和一个推荐；已明确的局部改写不强制菜单。审阅只报告问题，改写只触及已授权内容。

需要机械检查时尊重项目配置和既有文稿惯例；使用 Skill 配置则从 [Vale 目录](../skills/text-prison/vale/README.md)或 [AutoCorrect 目录](../skills/text-prison/autocorrect/README.md)选择适用入口。先核对版本、规则来源和输入范围，缺少前置项时该工具记 `Not Run`，不自动安装或同步。每轮选中引擎各检查一次，共用至多一次修订和一次复查；只审阅则只报告原文问题。诊断不扩大改写范围，也不能证明语义正确。

六个配置入口共享原创链接文字规则，并按用途逐项启用少量 Google 或 Microsoft 建议。科研、中文和混合配置不依赖第三方包；中文覆盖限于列出的泛指链接文字。规则和版本清单只在 Vale 目录维护，宿主路径只在 [INSTALL.md](INSTALL.md) 维护。

中文本地化摘要依据微软中文原文，排版建议参考中文社区约定，二者不等同。AutoCorrect 保守配置只建议混排间距，显式关闭其他已知规则和代码块处理；项目没有配置也不意味着允许全文统一空格。科研单位、公式、原样引用和界面标签仍需保护。固定版本的 stdin 按纯文本处理，因此 Markdown 只用已有文件，不为机械检查擅自创建文档。

## 不变的内容保护

表达优化不得改变主体、对象、否定、条件、可能与必然、数字及单位归属、因果、版本和引用对应。代码、命令、公式和原样引文默认保护。资料不足时指出缺口，不编造事实、前提或验收要求。

来源核对由当前写作者在任务内进行，不额外调用评审模型。Vale 只提供所选规则的机械诊断；不得把零提示或指令遵循写成语义保真通过。

## 安装与维护边界

仓库维护一份 Skill 源文件。npx 支持项目和全局范围，可选择链接或复制；共享链接指向同一份内容，独立副本分别维护。安装前核对范围、实际目标和已有内容，再保全相关锁记录与旧副本。README 主线不固定 CLI 版本，宿主路径和来源核对日期集中在 INSTALL；历史固定版本的安装结果不代表新版本已实测。

Python 安装器只支持项目范围，保留现有接口并拒绝覆盖，复制时精确排除生成的 Google、Microsoft 和 `.vale-config` 目录。上游包需用户授权同步，先核对安装内容与发布提交，再单列生成目录；共享链接先解析实际资源位置，不能按宿主数量重复同步。全局安装不等于允许修改用户所有项目。

未提供 hooks、MCP、CI、新的 Python 检查后端、JSON Schema 后端或自动修复循环。项目既有术语表保持单一来源，初版不另外生成词表。
