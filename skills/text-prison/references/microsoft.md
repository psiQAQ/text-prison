# Microsoft 产品帮助摘要

适用：产品帮助、界面说明、用户行动提示。先确定用户需要完成什么、当前知道什么。

- 把决定下一步的信息放在容易发现的位置，给出具体动作和对象。
- 按用户任务组织内容，避免用内部实现结构代替使用顺序。
- 保持术语与界面实际标签一致；已给定的按钮名、状态文字和产品名不因风格替换。
- 用直接、自然的语句，但不以“更短”为由删除条件或失败处理。
- 跨输入设备的操作可用中性动词；若鼠标、触摸等方式本身决定操作，保留具体动词。

Vale 的 UIVerbs 只给建议。例如需要说明滑动手势时，不能把 swipe 自动替换为 select。禁止调用上游规则的 action 批量修复，先判断上下文与授权。
