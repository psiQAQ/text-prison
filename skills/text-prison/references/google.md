# Google 技术文档摘要

适用：开发者 README、教程、API 说明及技术解释。项目既有风格和精确技术含义优先。

- 围绕读者要完成的任务安排必要信息；先交代条件，再给依赖条件的动作。
- 主体不明时补清主体。主动语态有助说明执行者时优先使用，不把被动语态一律判错。
- 同一个概念使用稳定术语；标识符与普通词区分排版，不改动 API 拼写。
- 顺序操作用有序列表，并列信息用列表或表格；不把连续论证硬拆成步骤。
- 精简重复内容，保留读者执行任务需要的前提、例外和示例。

组织原则由 Agent 应用。对应 Vale 配置只启用少量明确规则，不表示实现了完整 Google 指南；标题标点提示也不能越过“保留标题”的选择。
