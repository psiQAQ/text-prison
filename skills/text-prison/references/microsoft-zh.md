# 简体中文本地化摘要

适用于中文产品帮助、界面说明和技术文档的本地化；项目术语和实际界面标签优先，不把微软产品专用译法强加给其他产品。

- 先理解整段意图和读者任务，再组织自然中文，不逐词照搬英文顺序。
- 面向专业读者保留准确技术术语；面向普通读者解释必要概念，不以通俗为由替换成含义不同的词。
- 同一产品中的对象、按钮、状态和错误名称保持一致。有多个既有译法时，查实际产品上下文，不批量统一为一个常见词。
- 操作说明写清对象和条件；错误提示交代真实发生的情况及有依据的下一步，不编恢复动作。
- 可省去不影响指代的重复代词和赘词；保留否定、可能性、前提及科研限定，不把原指南中的营销简洁偏好用于删除事实。
- 区分界面字符串与说明文档。原指南对二者的括号和标点规定不同，因此不全局执行“中文一律全角”。命令、公式、数字和原样标签保持其实际格式。

以上是面向 TextPrison 的自主适配，不是 Microsoft Vale 包的中文翻译，也不声称覆盖微软完整本地化规范。中文间距的可选社区风格另见 [排版约定](chinese-typography.md)。
