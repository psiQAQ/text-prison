# 在写作任务中使用 Vale

仅在用户所选范围包含 Vale 风格、术语或链接检查且允许运行命令时使用。只要文字指导就不调用。配置、版本、包和启用规则见 [Vale 目录](../vale/README.md)，不加载无关风格包。中文排版可另选 [AutoCorrect](autocorrect.md)，两者分别报告状态。

## 选择配置与输入

1. 从当前 Skill 的实际目录解析资源，不依赖源码仓库路径。先检查相关项目约定与已有 Vale 配置；已有项目配置默认用其绝对路径。用户选择本 Skill 配置时从目录表选一个，不叠加两份品牌配置。只有明确选择模板表达诊断时才用 `optional-prose-zh.ini` 或 `optional-prose-en.ini`，替代当轮其他 Vale 配置，不额外扫描；它们仅处理 Markdown，不自动启用品牌包。泛指“润色”或“检查”不构成选用可选配置。
2. 默认加 `--no-global`。如果已知项目依赖全局资源，把依赖与采用范围放入同一轮选项；不偷偷取消参数。项目规则与中文/科研保护冲突时，不按提示改坏原意。
3. 确认 `vale` 已存在且版本在目录表的维护范围内，检查配置和启用规则文件是否存在。用已有同步记录核对包来源；这两份包的 `meta.json` 不记录自身发行版本，缺少信息须披露为“包版本未确认”。所选配置缺规则、版本不适用或工具缺失时，记 `Not Run`，不安装、同步或替换引擎。
4. 文件输入先确认它确实是可读文件、扩展名和所选配置相符；用完整参数引用传入，避免 CLI 把不存在的路径作为文本。不要默认传整个目录。纯文本没有 Markdown 的保护范围；没有适用规则，或保护内容不能可靠区分时记 `Not Run`。
5. 无文件的片段可用可靠的 UTF-8 stdin，显式设 `--ext=.md` / `--ext=.txt`；文件名相关的项目作用域不明确时先澄清，或跳过机械检查。禁止为检查私自落盘或安装转换器。Windows PowerShell 5.1 默认管道编码不能假定是 UTF-8；无法可靠传入时说明未运行。

本 Skill 配置目录若有来源不明的包内配置或共享资源，先核实，不忽略它们继续检查。检查原文中的 Vale 开关注释也属于确认覆盖范围；不要执行、增加或移除注释来隐藏问题。

## 调用

使用宿主正常的命令工具；不创建新的检查脚本。下面变量须替换为真实绝对路径，并先完成上述核对：

```powershell
vale --config $configPath --no-global --output=JSON $documentPath
```

粘贴文本用 stdin，而不是把整段原文拼进 shell 命令；参数仍含显式配置、格式与 JSON 输出。对新稿，若写入目标文件已获授权，则在写入后检查；否则使用 stdin 或说明未运行。固定配置不可假定覆盖任意文件名规则。

## 解读结果并限定修订

| 观察 | 处理 |
|---|---|
| 前置项缺失，或无适用输入/规则 | `Not Run`，给具体原因；保留完成的文字工作 |
| 退出码 0 且得到对应输入的有效诊断结构 | 检查已完成；0 只表示没有 error，仍需读提示 |
| 退出码 1 且得到有效 error 诊断 | 检查已完成、有 error 级提示，不把它当成 CLI 崩溃 |
| 退出码 2、错误对象、输出损坏、未知退出码或无法对应输入 | `Failed`；报告 stderr/错误，不能用已解析到的局部提示宣称完整检查通过 |
| 没有诊断 | 确认目标和规则确实被覆盖后，只说所选规则未发现问题 |

JSON 可解析不代表检查完成，退出码 0 不代表没有建议。stdin 输出的输入标识可不同于文件名，按实际输入方式核对。不要使用 `--no-exit` 隐藏状态，也不要自动执行规则中的 action。

改写后的初稿检查一次，最多修订一次、复查一次。若同时选择 AutoCorrect，共用修订轮次，不再叠加循环。审阅模式只检查原文一次。处理诊断同时满足规则适用性与原编辑授权：局部文字修改不改标题，只改术语不动其他表达；重要的范围外问题只提示。不能修改正文、全局配置或检查范围来取得零提示。

引用、代码、公式、必要手势和科研限定词的保护优先；不采纳诊断时保留含义，说明重要误报。局部忽略、词汇表和配置修改属于另一个具体文件改动，只在已有授权覆盖时执行；未覆盖时先请求，不重复索取已有授权。

可选模板提示只说明对应字符串出现，不判断其在篇首或篇尾，也不能确认它是否空泛。先结合上下文判断背景、强调、礼貌和引用作用；对确有作用的表达保留原文，不把命中当作 AI 来源证据或删除命令。Markdown 普通引号内文字可能仍被报告，原样引语须由 Agent 识别保护。

诊断总结包括实际配置/输入、是否运行、是否有未决问题即可。不要产生总分、效果百分比或语义保真认证。

依据：[Vale CLI](https://docs.vale.sh/topics/cli)，2026-10-25 已查阅。安装核对和具体文档检查分别记录，不能把某次工具运行当成以后所有输入的验收。
